## 추천 학습 경로

업로드 순서는 그대로 두었지만, 개념을 연결해서 공부할 때는 다음 순서를 권합니다.

1. [머신러닝](05_머신러닝.md): 학습 유형, 데이터 전처리, 모델의 기본 구조를 이해합니다.
2. [미분](07_미분.md) → [경사하강법](01_경사하강법.md): 기울기와 가중치 업데이트를 연결합니다.
3. [딥러닝 교재](03_딥러닝.md) → [딥러닝 학습 최종 정리](04_딥러닝_학습_요약.md): 퍼셉트론에서 역전파와 학습 루프까지 연결합니다.
4. [다중 분류 손실](06_다중분류_손실.md): Softmax와 Cross-Entropy를 예제로 복습합니다.
5. [모델 검증 및 평가](02_모델검증_및_평가.md): 학습한 모델이 쓸 만한지 지표로 판단합니다.

## 복습 방법

- 먼저 각 문서의 `핵심 요약`을 읽습니다.
- 공식을 보고 변수의 의미를 말로 설명합니다.
- 예제를 직접 계산하거나 코드에 손으로 값을 대입합니다.
- 마지막 `자기 점검` 질문을 답한 후, 틀린 부분만 원본 페이지를 다시 봅니다.

## 저장소에 올리기

1. 이 ZIP을 풀어 `AI-BOOTCAMP-STUDY` 폴더를 확인합니다.
2. GitHub에서 새 저장소를 만들고 저장소 이름을 `AI-BOOTCAMP-STUDY`로 정합니다.
3. `README.md`와 7개 폴더를 저장소 루트에 업로드합니다. 폴더별 Markdown은 GitHub에서 바로 읽을 수 있습니다.
4. GitHub 연결을 완료한 환경에서는 저장소 주소와 원하는 대상 브랜치를 확인한 뒤 직접 반영할 수 있습니다.
